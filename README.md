# JT Perfume

Official JT Perfumes website — a one-page site for small 10 mL fragrances, starting with Alexander at $20 USD.

The whole site is in `index.html`. Checkout remains disabled until the business's separate payment account and policies are ready.

Deployment: `.github/workflows/deploy.yml` publishes this site to GitHub Pages on pushes to `main` and on manual workflow dispatch.
